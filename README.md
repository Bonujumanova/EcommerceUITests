# UI-автотесты интернет-магазина: <a href="https://www.sima-land.ru/">Сима-ленд</a> 


В проекте реализован сквозной пользовательский сценарий: от выбора категории и товара до добавления товара в корзину и оформления доставки.


## 🛠 Используемые технологии

* **Python**
* **Pytest**
* **Selenium**
* **Page Object Model (POM)**
* **Pytest fixtures**
  

## 🎯 Цель проекта

Цель проекта — автоматизировать полный пользовательский сценарий интернет-магазина и получить практический опыт разработки UI-автотестов.

## 🧪 Что проверяется

- переход между страницами магазина;
- выбор категории и подкатегории;
- выбор товара;
- выбор размера;
- добавление товара в корзину;
- проверка товара в корзине;
- проверка итоговой стоимости;
- оформление заказа;
- заполнение данных доставки;
- проверка результата оформления заказа.

## 🏗 Архитектура проекта

Проект построен с использованием **Page Object Model (POM)**.

POM позволяет отделить логику взаимодействия со страницей от тестовых сценариев и сделать тесты более читаемыми и поддерживаемыми.

### Структура проекта

```text
EcommerceUITests/
│
├── base/                   # Базовые методы для работы с UI
│
├── pages/                  # Page Object классы
│
├── screen/                 # Скриншоты результатов тестов
│
├── tests/                  # UI-автотесты
│
├── utilities/               # Вспомогательные функции
│
├── conftest.py             # Конфигурация и фикстуры Pytest
│
├── LICENSE
└── README.md
```

## 📦 Base

Директория `base` содержит общие методы, которые могут использоваться в разных тестах.

Например:

* получение текущего URL;
* проверки значений элементов;
* создание и сохранение скриншотов.

Использование базовых методов позволяет не дублировать одинаковый код в Page Object классах и тестах.

## 📄 Pages

Директория `pages` содержит **Page Object классы**.

Каждый класс отвечает за взаимодействие с определённой страницей или частью пользовательского интерфейса.

В Page Object находятся:

* локаторы элементов;
* действия пользователя;
* методы взаимодействия с UI;
* проверки состояния страницы.

## 🧪 Tests

Директория `tests` содержит тестовые сценарии.

Основной сценарий проверяет полный пользовательский путь:

1. Открытие главной страницы.
2. Выбор категории товара.
3. Выбор подкатегории.
4. Выбор нужного товара.
5. Выбор размера.
6. Добавление товара в корзину.
7. Проверка добавленного товара.
8. Проверка итоговой стоимости.
9. Переход к оформлению заказа.
10. Выбор способа доставки.
11. Заполнение данных пользователя.
12. Оформление доставки.
13. Проверка финальной страницы.
14. Сохранение скриншота результата.

## 📸 Скриншоты

Во время выполнения теста создаётся скриншот финальной страницы после оформления заказа.

Скриншот позволяет визуально проверить результат выполнения сценария и сохранить информацию о сформированном заказе.

Скриншоты сохраняются в директории:

```text
screen/
```


## ▶️ Установка

Клонировать репозиторий:

```bash
git clone https://github.com/Bonujumanova/EcommerceUITests.git
cd EcommerceUITests
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать виртуальное окружение.

### Linux / macOS

```bash
source .venv/bin/activate
```


## ▶️ Запуск тестов

Запустить все тесты:

```bash
pytest
```
